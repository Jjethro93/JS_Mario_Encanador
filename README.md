<h1> Super Plumber – Seu Encanador do Reino dos Canos! </h1>
<br>
<br>
<h2> Sobre o projeto </h2>
<p> Super Plumber é um site de serviços de encanamento inspirado no universo do Super Mario! 
</p>
<br>
<p >📽 Desenvolvido durante o curso de programação, o projeto une criatividade, funcionalidade e um toque nostálgico de games clássicos.
O objetivo do site é oferecer um canal simples e divertido para que clientes possam:
</p>
<ul>
<li>  Conhecer os serviços de encanamento disponíveis</li>
<li>Preencher um formulário de solicitação de serviço</li>
<li>Entrar em contato diretamente via WhatsApp</li>
<li>Tudo isso dentro de um design temático, colorido e cheio de referências ao universo do Mario Bros! </li>
</ul>


<h2>Tecnologias utilizadas 🌐</h2>
<ul>
<li> HTML5 – Estrutura do site </li>
<li> CSS3 – Estilo e design inspirado em Mario </li>
<li>JavaScript – Funcionalidades interativas </li>
<li>WhatsApp API – Integração para contato direto </li>
</ul>

<h2> Funcionalidades ⚙️ </h2>
<ul>
<li> Formulário de contato com campos validados </li>
<li> Link direto para conversa no WhatsApp </li>
<li> Layout responsivo e amigável em qualquer dispositivo </li>
<li> Design temático e divertido, com elementos inspirados no Reino dos Cogumelos </li>
</ul>
